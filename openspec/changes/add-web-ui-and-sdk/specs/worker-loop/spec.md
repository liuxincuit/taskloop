# Spec Delta

## Purpose

定义轮询循环的生命周期与执行语义，使循环能够在不退出宿主进程的前提下被反复启动和停止，并对外提供足以回答"它现在在做什么"的状态。

## ADDED Requirements

### Requirement: 循环可独立启停

系统 SHALL 允许在宿主进程存活期间启动和停止轮询循环，停止循环 MUST NOT 终止宿主进程。

#### Scenario: 启动后按间隔重复执行轮次

- **WHEN** 用户启动循环
- **THEN** 系统立即执行第一轮，之后每经过 `intervalSeconds` 秒执行下一轮，轮次序号递增

#### Scenario: 停止后不再开始新轮次

- **WHEN** 循环处于运行状态且用户请求停止
- **THEN** 系统不再开始新的轮次，宿主进程保持运行并继续响应请求

#### Scenario: 停止状态下启动

- **WHEN** 循环处于停止状态且用户请求启动
- **THEN** 系统立即执行一轮，轮次序号在原序号基础上继续递增

### Requirement: 停止是协作式中止

系统 SHALL 在停止时中止正在执行的 agent 任务，而不是等待其自行结束。

#### Scenario: 停止时有任务在跑

- **WHEN** 用户请求停止，且当前有 agent 任务正在执行
- **THEN** 系统中止该任务，任务记录为"已中止"，随后进入停止状态

#### Scenario: 停止时有任务等待选中

- **WHEN** 用户请求停止，且本轮内还有候选任务尚未开始执行
- **THEN** 系统不再执行这些任务，它们不产生执行记录

#### Scenario: 停止中的中间状态

- **WHEN** 停止请求已发出但当前任务尚未完全中止
- **THEN** 系统对外报告"停止中"状态，`MUST NOT` 报告为"已停止"

### Requirement: 立即执行一轮

系统 SHALL 允许在等待下一次唤醒期间立即开始下一轮。

#### Scenario: 等待期间请求立即执行

- **WHEN** 循环处于运行状态并正在等待下一次唤醒，用户请求立即执行一轮
- **THEN** 系统立即结束等待并开始下一轮，轮次序号递增

#### Scenario: 停止状态下请求立即执行

- **WHEN** 循环处于停止状态，用户请求立即执行一轮
- **THEN** 系统不执行任何轮次，并报告循环未运行

### Requirement: 单轮内同一任务只执行一次

系统 SHALL 在单轮内对同一任务标识最多执行一次，即使多条规则命中同一任务。

#### Scenario: 多条规则命中同一任务

- **WHEN** 同一轮内第一条规则与第二条规则都抓取到同一个任务
- **THEN** 系统只对该任务执行一次 agent 任务，第二次命中被跳过

### Requirement: 单点失败不中断整轮

系统 SHALL 在单个规则抓取失败、模板渲染失败或任务执行失败时记录错误并继续处理后续规则与任务。

#### Scenario: 规则抓取失败

- **WHEN** 某条规则在抓取阶段抛出错误
- **THEN** 系统记录该规则失败原因，跳过该规则并继续处理后续规则

#### Scenario: 任务执行失败

- **WHEN** 某个任务的 agent 执行以失败结束
- **THEN** 系统记录失败原因，并继续处理本轮剩余候选任务

### Requirement: 轮次与任务状态可查询

系统 SHALL 对外提供当前循环状态快照，包括运行状态、当前轮次数、下次唤醒剩余时间和本轮各规则的处理进度。

#### Scenario: 运行中查询状态

- **WHEN** 循环运行中且已进入第二轮
- **THEN** 查询返回运行状态、轮次序号为 2、以及下次唤醒的剩余秒数

#### Scenario: 停止后查询状态

- **WHEN** 循环已停止
- **THEN** 查询返回停止状态，且不包含唤醒剩余时间
