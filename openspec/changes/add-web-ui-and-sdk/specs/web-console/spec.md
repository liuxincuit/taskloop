# Spec Delta

## Purpose

定义浏览器界面的行为契约：如何展示循环与任务的实时进度、如何通过界面控制循环启停，以及在没有外网的环境中如何自包含地渲染。

## ADDED Requirements

### Requirement: 仅监听回环地址

Web 服务 MUST 绑定回环地址（`127.0.0.1`），`MUST NOT` 监听所有网络接口。

#### Scenario: 启动 Web 服务

- **WHEN** 用户以页面模式启动
- **THEN** 服务监听 `127.0.0.1`，局域网内其他机器无法访问

#### Scenario: 端口被占用

- **WHEN** 默认端口已被其他进程占用
- **THEN** 服务以明确的错误信息退出，指出占用的端口

### Requirement: 进度按层级展示

系统 SHALL 在进度视图中按"轮次 → 规则 → 任务 → 执行明细"的层级展示执行过程，并对系统事件、工具调用、agent 文本使用可区分的视觉层次。

#### Scenario: 任务执行中

- **WHEN** agent 正在执行某个任务并已产生工具调用
- **THEN** 页面在该任务下依次展示工具调用记录，并持续追加 agent 的文本输出

#### Scenario: 规则无候选任务

- **WHEN** 某条规则本轮未抓取到符合条件的候选任务
- **THEN** 页面在该规则下显示无候选，而不是隐藏该规则

#### Scenario: 规则抓取失败

- **WHEN** 某条规则本轮抓取失败
- **THEN** 页面在该规则下显示失败原因

### Requirement: 进度实时推送

系统 SHALL 通过服务器推送事件向页面推送执行进度，`MUST NOT` 要求页面轮询获取。

#### Scenario: 建立推送连接

- **WHEN** 页面加载完成
- **THEN** 页面建立长连接并开始接收进度事件

#### Scenario: 连接中断后恢复

- **WHEN** 推送连接因网络或休眠中断
- **THEN** 页面自动重连，并重新获取一次完整状态快照以补齐缺失进度

### Requirement: 控制循环启停

系统 SHALL 提供启动、停止和立即执行一轮三个控制操作，并在这三个操作不可用时明确表示。

#### Scenario: 运行中

- **WHEN** 循环处于运行状态
- **THEN** 页面显示停止与立即执行一轮操作，启动操作不可用

#### Scenario: 停止后

- **WHEN** 循环处于停止状态
- **THEN** 页面显示启动操作，停止与立即执行一轮操作不可用

#### Scenario: 停止中

- **WHEN** 循环处于停止中的中间状态
- **THEN** 页面的所有控制操作均不可用，并显示正在中止

### Requirement: 停止需要二次确认

系统 SHALL 在执行停止前要求用户确认，且确认操作 MUST 在页面内就地展开，`MUST NOT` 在停止前直接生效。

#### Scenario: 用户点击停止

- **WHEN** 用户点击停止操作
- **THEN** 页面显示确认与取消两个选择，循环仍在运行

#### Scenario: 用户确认停止

- **WHEN** 用户在确认提示中选择确认
- **THEN** 系统开始中止当前任务并进入停止中状态

#### Scenario: 用户取消停止

- **WHEN** 用户在确认提示中选择取消
- **THEN** 页面恢复原来的控制操作，循环状态不变

### Requirement: 停止后展示上一次运行结果

系统 SHALL 在循环停止时展示上一次运行的完整任务结果摘要，而不是只显示空白区域。

#### Scenario: 停止后查看

- **WHEN** 循环已停止且上一次运行处理过任务
- **THEN** 页面展示上一轮的任务标识、成功或失败状态、耗时，以及失败原因

#### Scenario: 从未运行过

- **WHEN** 循环从未启动过
- **THEN** 页面显示引导性提示而不是空列表

### Requirement: 页面不依赖外部资源

页面 MUST 不引用任何外部域名下的样式、脚本、字体或图片资源，以便在无外网环境中正常渲染。

#### Scenario: 无外网环境打开页面

- **WHEN** 运行环境无法访问互联网
- **THEN** 页面的样式、脚本和字体全部正常加载并生效

### Requirement: 可访问性与降级

页面 MUST 提供键盘可见的焦点样式，并在用户启用减少动态效果时关闭非必要动画。

#### Scenario: 键盘导航

- **WHEN** 用户以键盘 Tab 键在控制操作之间移动焦点
- **THEN** 当前焦点元素具有可见的焦点样式

#### Scenario: 系统要求减少动态效果

- **WHEN** 用户的操作系统启用了减少动态效果偏好
- **THEN** 页面的循环动画被关闭
